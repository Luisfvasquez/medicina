# Explore Summary — LUCA Health OS

**LUCA Health OS** es una plataforma integral de gestión de consultorios médicos para Latinoamérica. Es un API REST en Laravel 13.8 / PHP 8.3 con autenticación JWT de doble guardia que separa profesionales (médicos, farmacias, admins) de pacientes. El backend cubre 6 fases de desarrollo con **170+ endpoints**, **46 controladores**, **35+ modelos Eloquent** y **21 enums PHP** en dominios que incluyen pacientes, consultas SOAP, turnos, prescripciones, marketplace B2B2C de farmacias, facturación, auditoría HIPAA y verificación KYC. Un endpoint de sync offline-first permite a los médicos trabajar sin conectividad. **El frontend está 0% implementado** — solo existe scaffold Vite + Tailwind. La documentación es excelente (12 specs) pero falta UI, tests y workers de cola.
